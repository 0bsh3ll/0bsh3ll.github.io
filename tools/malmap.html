MalMap — Visualizing ProcMon Captures as a Process Graph

📅 2026-07-17 ⏱ 6 min read 🕸️ ProcMon CSV → interactive graph
A zero-install browser tool that turns a Process Monitor CSV export into an interactive, filterable graph. Process trees, file, registry and network activity, and color-coded severity rings, in the dark-dashboard look of Microsoft Defender's blast radius view. Inspired by ProcDOT. Open index.html in a browser, import a CSV, and start reading behavior instead of rows. MalMap source on GitHub ↗

01 — The Problem

Detonate a sample with Process Monitor running and you get tens of thousands of rows: every RegQueryValue, every CreateFile, every thread start. The interesting part (a dropper writing an .exe into %TEMP%, a Run key, an outbound TCP connection) is in there somewhere, but you have to filter and scroll to find it.

ProcDOT solved this years ago by drawing the capture as a graph. I wanted something lighter that runs in any browser with nothing to install, handles whatever columns ProcMon exports, and looks like the incident graphs analysts already know from Defender.

02 — How It Works
01
Parse
A real quoted-CSV tokenizer handles commas and newlines inside quotes and "" escapes. Known ProcMon columns map to canonical fields, and any other column is kept under an auto camelCase key.
02
Build
Each event becomes an edge from the acting thread to its target: a child process, file, registry key or network endpoint. The edge is labeled with the operation name.
03
Score
One heuristic function rates every event as low, mid or high. A node takes the highest severity of any event that touches it.
04
Render
vis-network draws each node as an SVG puck: a dark circle, a white Lucide icon, and a severity ring. You can filter it, rearrange it, and drag nodes around.

Thread-centric nodes

A node is a (process, thread) pair labeled name (P-pid, T-tid). A single-threaded process is one node. Extra threads appear as sibling nodes connected by a new thread edge, so you can see which thread did the damage. In the screenshot, it's the second thread of invoice.exe that creates cmd.exe, not the main one.

Severity heuristic

RingTriggers
🟠 CriticalWriting to a Run/RunOnce key; creating, writing or renaming .exe .dll .scr .bat .cmd .ps1 .vbs .js files in Temp, AppData or ProgramData; TCP Connect / UDP Send
🟡 WarningAny process operation; registry set, create, delete or rename; file write, create, delete or rename
⚪ NormalReads, queries, closes and everything else
💡
All severity rules live in one function, scoreSeverity(event) in js/graph-builder.js. To tune detection for a malware family, you only need to edit that function.
03 — Features
FeatureWhat it does
Import CSVLoads any ProcMon CSV export. Columns can be in any order, and every column is preserved.
Process TreePicks a root process and shows only its subtree. Switching trees is instant, with no re-parse.
Node Type FiltersTurns process, file, registry and network nodes on or off, with live counts.
ArrangeA deterministic left-to-right tree layout built from the visible nodes only, so the same filter always gives the same picture.
Lock LayoutFreezes physics so you can drag one node without moving its neighbors.
04 — Quick Start
setup bash 
# No build step. It needs internet for two CDN scripts (vis-network, lucide).
git clone https://github.com/0bsh3ll/malmap.git && cd malmap
xdg-open index.html      # or: open index.html on macOS

In ProcMon, go to File → Save… → Comma-Separated Values. In MalMap, click Import CSV, pick a root from the Process Tree dropdown, and press Arrange. To try it without a capture, use the bundled samples/multi-tree.csv, which has three root trees covering every node type.

Expected format

Logfile.CSV csv 
"Time of Day","Process Name","PID","Operation","Path","Result","Detail"
ℹ️
Adding a TID column (Options → Select Columns → Thread ID) enables the per-thread view. Parent/child links come from the PID: N value in the Detail field of Process Create events. Thread links come from Thread ID: N in Thread Create events.

06 — What's Next

On the roadmap: search and highlight, a detail panel when you click a node (with the full ProcMon row), time scrubbing to replay a detonation, collapsible subtrees, and rooting the view at any mid-tree process.

⚠️
MalMap only reads a CSV that you export. It never runs the sample. Capture in an isolated analysis VM, and treat the severity rings as triage hints, not verdicts.
